# **BÀI 28: LIFECYCLE OF REACTIVE EFFECTS**

Bài 28 thực chất là **đào sâu Bài 26**. Những gì bạn vừa học về:

↓

↓

# **1\. Component lifecycle và Effect lifecycle là hai thứ khác nhau**

Component thường được nhìn:

MOUNT

Component xuất hiện

↓

UPDATE

props/state thay đổi

↓

UPDATE

↓

...

↓

UNMOUNT

Component biến mất

Ví dụ:

&lt;ChatRoom roomId="general" /&gt;

sau đó:

&lt;ChatRoom roomId="travel" /&gt;

Component ChatRoom **không nhất thiết bị unmount rồi mount lại**.

Nó vẫn là component đó, chỉ nhận:

roomId

general → travel

và render lại.

# **2\. Effect thì đừng nghĩ Mount → Update → Unmount**
