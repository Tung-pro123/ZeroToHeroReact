# **2\. DOM node thật nghĩa là gì?**

Khi bạn viết JSX:

&lt;input /&gt;

đây là JSX mô tả UI.

Cuối cùng browser phải có DOM thật tương ứng:

&lt;input&gt;

Và DOM element đó có những API của browser như:

element.focus();

element.blur();

element.scrollIntoView();

Ví dụ JavaScript thuần ngày xưa bạn có thể làm:

const input =

document.querySelector("#name");

input.focus();

Trong React, thay vì tự đi tìm:

document.querySelector(...)

ta thường để React đưa DOM node đó cho mình thông qua Ref.

# **9\. Render và Commit phải phân biệt**

Bạn đã học render nên bài này nối thẳng vào kiến thức đó.

Khi state/props thay đổi:

Trigger

↓

Render

↓

Commit

### **Render**

React gọi component:

function Form() {

...

return &lt;input ref={inputRef} /&gt;;

}

React đang **tính toán UI tiếp theo**.

### **Commit**

React áp dụng những thay đổi cần thiết lên DOM.

RENDER

"Tôi muốn có &lt;input&gt;"

↓

COMMIT

DOM thật được tạo/cập nhật

↓

React cập nhật DOM ref

Vì vậy DOM Ref đặc biệt gắn với **commit phase**.

# **31\. Câu hỏi phỏng vấn rất hay**

## **37\. Vì sao cần lấy DOM &lt;input&gt; đó?**

Vì nếu chỉ muốn **hiển thị input**:

&lt;input /&gt;

"Ê browser, focus đúng cái input này cho tao."

thì bạn cần **DOM object thật** để gọi:

inputElement.focus();

Và Ref cho bạn lấy được inputElement:

↓

## **40\. ref={inputRef} có thể đọc bằng tiếng Việt như thế này**

Khi thấy:

const inputRef = useRef(null);

&lt;input ref={inputRef} /&gt;

hãy đọc:

**"React ơi, cứ render &lt;input&gt; bình thường. Nhưng sau khi DOM này được commit, hãy cho inputRef.current tham chiếu tới DOM &lt;input&gt; đó để lát nữa tôi còn thao tác với nó."**

Vậy hai chuyện hoàn toàn riêng:

&lt;input /&gt;

│

└── TẠO/HIỂN THỊ input

&lt;input ref={inputRef} /&gt;

│

└── ngoài việc hiển thị input,

còn cho inputRef.current

THAM CHIẾU tới DOM input

### **Câu chốt**

Không có ref

→ input VẪN tồn tại

→ chỉ là ta không lấy DOM node đó thông qua inputRef

Có ref

→ + inputRef.current trỏ tới DOM input

→ ta gọi được .focus(), .scrollIntoView(), ...
