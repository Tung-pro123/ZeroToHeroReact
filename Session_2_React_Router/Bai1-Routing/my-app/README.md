# 🌐 Interactive Lab - Session 2 Bài 1: Routing (Cấu Hình Định Tuyến Cơ Bản)

Dự án thực hành nền tảng về **Client-Side Routing & Nested Routes** thuộc khóa học **ZeroToHeroReact**.

## 🚀 Khởi chạy ứng dụng

```bash
cd Session_2_React_Router/Bai1-Routing/my-app
npm install
npm run dev
```

Mở trình duyệt tại: **http://localhost:3021**

## 🎯 Các tính năng & Phòng thí nghiệm trực quan

1. **🌐 Client-Side Routing vs Server-Side Routing**: Phân tích trực quan cơ chế hoạt động giữa mô hình truyền thống (Full Page Reload) và SPA (Virtual DOM Swap).
2. **🧩 The Core Trio: BrowserRouter, Routes & Route**: Giải mã cấu trúc bảng ánh xạ URL $\rightarrow$ Component UI.
3. **🏛️ Nested Routes & Layouts with `<Outlet />`**: Khám phá kiến trúc phân tầng giao diện, giữ nguyên Header/Sidebar khi nội dung con thay đổi.
4. **📍 Index Route & Relative Paths**: Bản chất của `index` route (trang mặc định khi URL khớp với cha) và đường dẫn tương đối.
5. **🎯 Dynamic Segments (`:id`) & useParams()**: Bóc tách tham số URL động.
6. **🚫 Wildcard 404 Route (`*`)**: Xử lý trang lỗi không tìm thấy đường dẫn.
7. **📝 Senior Architect Quiz**: 5 câu hỏi phỏng vấn kiến trúc chuyên sâu.
